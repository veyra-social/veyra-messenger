# Veyra

Veyra — P2P-мессенджер с приложениями для настольных и мобильных устройств. Интерфейс написан на React и TypeScript, сетевой клиент и локальное хранилище — на Rust.

## Готовые сборки

Готовые сборки Veyra для всех поддерживаемых операционных систем можно скачать на [странице загрузок](https://veyra.social/downloads).

## Первое подключение

В этой сборке новый профиль начинает работу с пустым каталогом bootstrap-нод. Чтобы подключиться через свою ноду, откройте **Меню → Сеть**, введите адрес ноды в формате `IP:порт`, нажмите **Проверить**, затем **Подключить**. В интерфейсе разработчика также доступен импорт пакета доступа. Для обнаружения соседей в локальной сети стартовый каталог не требуется.

## Разработка

Установите Node.js 22.12 или новее, Rust и системные зависимости Tauri для своей платформы. Выполните команды из корня проекта.

```sh
npm ci
npm run tauri dev
```

Проверки интерфейса и ядра можно запускать отдельно.

```sh
npm run build
npm run test:frontend
cargo test --manifest-path src-core/Cargo.toml --locked --lib
```

Исходники интерфейса находятся в `src-ui/`, ядро, платформенные ресурсы и проект Android — в `src-core/`. Ноды с доменами `.example` в тестах — фиктивные данные для проверки маршрутизации.
